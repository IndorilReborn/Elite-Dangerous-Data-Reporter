# Elite Dangerous Data Reporter

A tool for sending data to EDDN along with some handy side features:

- Silent Mode: Disable all EDDN reporting for a CMDR
- Find: Find the closest DSSA carrier, material trader, technology broker and more
- Route: Get a Spansh exact plotter route directly in the app and follow it to you destination.
  With automatic copy-paste for the next system when opening the galaxy map

## Note: Inara has not whitelisted this EDDN source yet, so data reported won't show up there for the time being
